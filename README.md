# MY SIMPLE GACHA

用扭蛋機抽籤的小工具，做給班級分組、分配任務用。貼上名單、寫好任務，按下去就會有一顆扭蛋掉出來，結果公平又有點儀式感。

**線上使用：<https://my-simple-gacha.vercel.app>**（打開就能用，不用安裝、不用登入）

## 功能

**兩種抽法**
- **抽組**：以「組」為單位抽，例如抽第 3 組去掃地。
- **抽個人**：以「人」為單位抽。

**輸入名單**
- 直接在表格裡填姓名和組別。
- **從 LINE 貼上**：把 LINE 記事本的留言整段貼進來，會自動辨識「第3組 王小明」「李大華 1組」「3 陳美美」等寫法。
- **從 Excel 貼上**：直接複製 Excel 的格子貼上。會自動判斷哪一欄是姓名、哪一欄是組別，學號和座號欄會被忽略。表頭、「組別1」這種寫法，以及組別只寫在每組第一列（合併儲存格）的表格都看得懂。貼上後會顯示辨識結果，判斷錯了可以直接在表格修改。

**任務**
- 每個任務有名稱和數量（例如「擦黑板 × 2」）。

**抽籤畫面**
- 扭蛋機動畫、像素風老師、8-bit 音效（可以靜音）。
- 按「下一個任務」會直接抽出第一顆，不用再多按一次。
- 還沒抽的任務可以**拖動排序**（或按 ▲▼），抽過的和抽到一半的會鎖住。
- 側邊會顯示已分配的結果和尚未抽到的人。
- 籤不夠時，後面的任務會不足額並提醒「少了幾組」，不會重複抽同一個人。
- 抽到一半可以回到設定修改名單或任務，選「繼續抽籤」會保留已抽出的結果，或選「重新開始」。

**紀錄，方便下次快速輸入**
- 名單和任務會**自動記住上次的內容**，重新整理也不會消失。
- 名單、任務都可以**命名存檔**（例如「三年二班」「大掃除」），之後從下拉選單一鍵載入。
- **抽籤進度也會保存**：抽到一半重新整理，會回到原本的畫面，已抽出的結果都還在。

## 資料存在哪裡

所有資料都只存在你自己瀏覽器的 `localStorage`，**沒有後端、不會上傳到任何伺服器**。因此：
- 換一台電腦、換一個瀏覽器，或清除瀏覽器資料，紀錄就不會跟著過去。
- 無痕模式或瀏覽器停用儲存時，抽籤仍然可以用，只是不會保存紀錄。

## 在自己的電腦上執行

這是純靜態網站（HTML、CSS、原生 JavaScript），沒有任何相依套件，也不需要建置。

```bash
# 直接用瀏覽器打開 index.html 就能用，或用任何靜態伺服器，例如：
npx serve
```

## 測試

需要 Node.js 20 以上：

```bash
npm test
```

測試涵蓋名單解析（LINE、Excel）、抽籤與任務排序邏輯、紀錄與進度的儲存。

## 專案結構

| 檔案 | 用途 |
| --- | --- |
| `index.html`、`styles.css` | 頁面與像素風樣式 |
| `src/parse.js` | 名單解析：LINE 貼上、Excel 貼上、表格資料轉換 |
| `src/draw.js` | 抽籤邏輯：籤池、抽出、下一個任務、任務排序、修改後繼續抽 |
| `src/store.js` | 紀錄：自動記住上次、命名存檔、抽籤進度 |
| `src/gacha.js`、`src/teacher.js`、`src/sfx.js` | 扭蛋機動畫、像素老師、音效 |
| `src/app.js` | 畫面與操作的串接 |
| `tests/` | 單元測試 |
| `docs/superpowers/` | 最初的設計說明與實作計畫 |

## 部署

部署在 Vercel，是純靜態網站。`.vercelignore` 排除了測試、文件和開發設定，只上傳網站本身。
