# 任務抽籤 設計規格


## 目的
課堂上投影使用的任務抽籤工具。老師輸入名單與任務，**一個任務一個任務**地抽出負責的組或人，
全班當場看結果。不保存資料，下次重新設定。

## 使用流程
1. **設定畫面**
   - 抽籤方式切換：**抽組**（預設）／**抽個人**。
   - 名單**表格**：欄位「姓名｜組別｜✕」，可新增／刪除列，在最後一列按 Enter 自動新增一列。
     組別留空（或不是正整數）＝未分組，該格以黃色標示。
   - 「從 LINE 貼上」：展開文字框，貼上 LINE 記事本留言後按「填入表格」，依下方解析規則拆成列，
     加到表格最後（先移除完全空白的列），並提示已填入人數、重複與略過的行。
   - 任務**表格**：欄位「任務｜數量｜✕」，數量留空或無效＝1。數量在抽組模式代表組數，在抽個人模式代表人數。
   - 即時**分組預覽**：`第1組（2人）：王小明、李大華`；未填組別者列在「未分組」。
   - 提示訊息：錯誤（阻擋開始）與警告（不阻擋）。
   - 「開始抽籤」按鈕，有錯誤時停用。
2. **抽籤畫面**（投影用大字）
   - 顯示「任務 i / N」、任務名稱、要抽幾組／幾人。
   - **極簡扭蛋機**：米白背景、單一墨色線條的圓形球罩＋方形底座（旋鈕、出球口）。
     球是扁平雙色膠囊（上半淺、下半深），顏色依組別取自 5 色低彩度色盤，未分組為灰色。
     球罩內的球數＝尚未抽到的數量，球會依數量縮放、受重力堆疊並互相碰撞；機器下方顯示「球池剩 N 顆」。
   - **一次抽一顆**：按「抽！」→ 旋鈕轉一圈、球被攪動約 1 秒 → 一顆球從球罩消失（球數真的減少）
     → 從出球口掉出並飛到右側放大 → 膠囊晃動、上殼掀開 → 卡片彈出，大字顯示組名／姓名，
     下方為組員（抽組）或組別（抽個人）。開出的球以小圓標籤列在「這個任務已抽出」。
   - 任務未抽滿時按鈕顯示「再抽！（還要 N 組／人）」；抽滿（或球池空了）才出現「下一個任務」
     （最後一個任務改為「看結果」）。動畫進行中不接受點擊。
   - 系統設定「減少動態效果」時略過動畫，直接顯示卡片。
   - 側欄：已分配清單、尚未抽到的清單與數量。
3. **結果畫面**：表格列出每個任務與抽中者，另列「未抽到」；按鈕「重新抽」（同設定重抽）與「回到設定」。

## 規則
- **不重複**：抽中的組／人從抽籤池移除。
- **不足額**：剩餘數量少於任務需求時，剩下的全部分給該任務，並顯示「剩下的不夠，少了 X 組／人」，不報錯。
- 開始前若任務總需求 > 抽籤池大小，顯示警告（不阻擋）。
- 錯誤（阻擋開始）：抽組模式沒有任何組別 →「沒有辨識到任何組別」；抽個人模式名單空 →「名單是空的」；沒有任務 →「請至少輸入一個任務」。
- 抽組模式下，未分組的學生不列入抽籤，並顯示警告。抽個人模式下，未分組學生照常抽，標示「未分組」。

## LINE 名單解析規則（「從 LINE 貼上」時，每一行）
1. 全形數字轉半形；去掉日期（`2026/09/23`）與時間（`14:02`、`下午2:05`）。
2. 依序嘗試辨識組別，第一個成功者為準：
   1. `第N組`／`第N组`（N 可為阿拉伯數字或中文數字 一～九十九，含「兩」）
   2. `N組`／`N组`
   3. 行首數字＋分隔符（`3 王小明`、`3. 王小明`、`3、王小明`）
   4. 行尾分隔符＋數字（`王小明 3`）
3. 去掉組別字樣後，剩下的文字（去除頭尾標點、合併空白）為姓名。
4. 有組別但沒有姓名的行（例如只有 `第4組`）→ 略過並提示。
5. 重複姓名只保留第一次，並提示。
6. 已知限制：行尾的座號（`王小明 05`）會被當成組別；老師可在表格中直接修正。

## 技術
- 純 HTML + CSS + 原生 JS，**無建置、無相依套件**，雙擊 `index.html`（file://）即可使用 →
  使用傳統 `<script>`（不用 ES modules，file:// 下會被 CORS 擋）。
- 每個 JS 檔用 UMD 小包裝：Node 中 `module.exports`，瀏覽器中掛在 `window.DrawLots`。
- 純邏輯用 `node --test` 做單元測試；扭蛋機（物理、上色、出球開球）集中在 `src/gacha.js`，日後可換風格。
- 不做：保存、匯出、框架。
